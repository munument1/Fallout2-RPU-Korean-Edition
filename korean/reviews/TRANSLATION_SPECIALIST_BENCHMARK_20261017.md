# Fallout 2 RPU: 번역 특화 로컬 모델 검증 (2026-10-17)

## 목적과 검증 범위

- GPU: GeForce RTX 5070 Ti 16GB. 테스트 모두 로컬 Ollama 서버에서 수행.
- 실험 모델: Tencent 공식 Hy-MT2-7B-GGUF Q8_0(약 8.0GB), TranslateGemma 12B Ollama Q4_K_M(약 8.1GB).
- 공통 기본 조건: **영어 원문만** 받아 단일 한국어 번역 출력. 원래 오역/정답 문장은 모델에 공개하지 않음.
- 두 모델의 공식 번역 프롬프트를 각각 사용. NPC 정보나 용어집 없이 12개 핵심 사례 + 이전 수동 검수 기록 8명에서 균형 있게 고른 **100개 서로 다른 ID**를 번역.
- 100개의 원본 영어, 기존 정밀 검수 최종 한국어, 두 모델의 번역 결과, 말투 판정은
  [TRANSLATION_MODELS_GOLD100_20261017.csv](TRANSLATION_MODELS_GOLD100_20261017.csv).
- 테스트 자동화 코드: korean/benchmark_translation_specialists.py.
- 별도로 6개 문장에서 NPC 배경 설명/용어집을 주었을 때의 반응 검증.

## 실행 및 구조 검사

| 항목 | Hy-MT2-7B Q8 | TranslateGemma 12B |
|---|---:|---:|
| 100개 독립 번역 완료 | 100/100 | 100/100 |
| 응답 실패 | 0 | 0 |
| 번역 결과 CP949 인코딩 실패 | 0 | 0 |
| 첫 실행/모델 로딩 포함 소요시간 합 | 88.1초 | 92.6초 |
| 문장당 소요시간 중앙값 | 0.79초 | 0.83초 |
| 종결 말투 판정 가능한 비교군 | 80개 | 83개 |
| 수동 교정본 종결 말투와 일치 | 23/80(28.8%) | 21/83(25.3%) |

**주의:** 말투 일치율은 기존 audit_dialogue_register.classify()의 간이 종결어미
분류가 두 문장의 끝을 같게 인식한 비율이다. 한 문장에 섞인 말투, 문맥에 따른
타당한 전환, 원문의 뜻과 문학적 품질은 반영하지 않으므로 **실제 번역 정확도가
28.8% 또는 25.3%라는 뜻이 절대로 아니다.** 샘플은 과거 수정 기록에서만 선별했으므로
모든 RPU 대사에 대한 무작위 일반화도 불가능하다.

## 핵심 오역 12개 기본 번역: 질적 판단

- **좋았던 부분:** 두 번역 특화 모델 모두 epitaph를 비문, salvation을 구원,
  soap을 비누, pretty new here를 새로 온 사람이라는 뜻으로 번역.
  기존 로컬 범용 모델에 비해 이 사례에서는 핵심 의미 파악이 명확히 개선됨.
- **Hy-MT2가 우세했던 사례:** Vertibird를 '버티버드'로 보존하고,
  지역 정보와 대사 연결을 상대적으로 자연스럽게 구성함.
- **두 모델의 오류:** taking you out of the picture를 살해 위협이 아닌
  단순 업무 배제처럼 해석, pasture pies를 동물 배설물이 아닌 파이/초원으로 해석,
  Red menace의 반공주의 맥락 누락, We have felt better가
  현재 좋지 않은 컨디션을 암시한다는 의미 누락.
- **특히 문제가 되는 부분:** 수동 검수본의 술릭 반말, 고리스 하오체,
  마커스 하오체, 장로 하게체 등이 범용 존댓말로 바뀜.
  영어 원문만으로는 해당 한국어 화법을 복원할 단서가 부족함.

## 맥락·용어집을 제공한 6개 추가 시험

각 모델에 동일한 NPC 역할 설명과 게임 용어 배경 정보를 별도 문장으로 부여.
기존 한국어 정답/교정문은 보여주지 않음.

| ID | 문맥 없는 문제 | 맥락 제공 후 관찰 |
|---|---|---|
| 리처드슨 250 | TranslateGemma가 Vertibird를 일반 수송기로 처리 | 둘 다 '버티버드' 보존, Hy-MT2 하대 어조도 개선 |
| 리처드슨 266 | 죽음을 암시하는 대사의 격식 과다 | 둘 다 묘비/비석을 언급, Hy-MT2는 footnote를 '발자취'로 오역 |
| 리처드슨 276 | '그림에서 제외' 식 직역 | 둘 다 직접 처리한다는 위협으로 개선 |
| 술릭 711 | 어색한 주어·말투 | 둘 다 비누/조건 유지. '우리와 나' 어법은 추가 교열 필요 |
| 술릭 731 | pasture pies 관용구 미해석 | Hy-MT2가 풀밭의 똥/파리 비유와 '끌어들인다'는 핵심까지 보존. TranslateGemma는 소똥을 알아봐도 행위 주체·의미 변형 |
| 리처드슨 218 | Red menace를 빨간 괴물/모호한 빨간 위협으로 처리 | TranslateGemma가 공산주의 세력으로 이해, Hy-MT2는 적색 위협이라고 번역 |

### 결론

**이 환경에서 Hy-MT2-7B Q8을 1차 번역 초안 생성기로 추천하며,
TranslateGemma 12B를 독립 비교용으로 유지한다.**
장면 정보·용어집을 함께 제공하는 것이 핵심이다. 다만 100개 기계적 말투 검사는
원문만 제공했을 때 어느 모델도 프로젝트 고유 화법을 안정적으로 재현하지 못함을 보여줌.

두 모델의 출력이 같더라도 둘 다 틀린 사례가 있으므로 **일치했다고 자동 승인하면 안 됨**.
특정 대사 실제 수정에는 NPC/PC 역할, SSL 조건, 전후 문맥, 의미, 격식, 고유명사,
CP949/MSG ID/음성/기호/줄바꿈 보존을 별도 검증해야 한다.

이번 실험은 번역 파일을 수정하지 않았다. 앞서 품질 문제로 중지한 매일 03:00
로컬 자동 검수 예약은 **계속 중지 상태**이며 자동 일괄 덮어쓰기/릴리스도 하지 않는다.
