## 결론

**qwen3:14b 및 gemma4:latest는 Fallout 2 RPU 최종 번역을 일괄 자동 교정하기에 부적합.**
누락 탐지 등 저위험 용도의 보조 후보 생성기로만 활용할 수 있으며,
제안 확신도는 실제 정확도와 일치하지 않는다.
Windows 작업 스케줄러 Fallout2-RPU-Overnight-Review는 이번 실측 결과를 근거로
**중지(Disabled)**했으며, GitHub Actions의 규칙 기반 검사에는 영향을 주지 않았다.

## 소규모 대조 시험

- 기존 고확신 수동 교정 로그에서 8개를 골라 원래 **잘못된 한국어**를 모델에 보여줌.
- 같은 영어 문장에 이미 교정이 끝난 한국어 8개를 제공해 불필요한 수정을 평가.
- 모델: Windows Ollama의 qwen3:14b, gemma4:latest.
- 8개를 한 묶음으로 제공하는 비교 실험. 파일별 주변 대화 전체를 제공하지 않았으므로,
  이 수치는 일반적인 모델 정확도나 모든 실전 호출 성능을 대표하지 않는다.

구체 사례:

1. kcsulik.msg ID 711: soap=비누인데 기존 오역이 수프. Qwen3는 **비누로 바꾸어야 한다고 설명해 놓고** 실제 제안에는 수프를 유지했다.
   Gemma4는 비누를 고쳤지만 캐릭터의 독특한 화법을 필요 이상으로 변경했다.

4. ocgoris.msg ID 144: new here=이곳에 온 지 얼마 안 됨인데 지식인으로 오역.
   Gemma4는 문제를 지적하고도 '지식인'을 유지함.

## 안전 원칙

- korean-auto-review의 후보 보고서는 정답이나 커밋 예정 수정본이 아님.
- 높은 confidence를 자동 수정을 허가하는 기준으로 사용하지 않음.
- 기존 CP949 MSG 파일, 영어 파일, manifest 및 정식 릴리스는 검증 실험에서 수정하지 않음.
- 대규모 수정 자동화를 재개하려면 클라우드급 번역/추론 모델과
  화자별 영어·SSL 맥락, 보수적 독립 재검수, CP949·ID·음성·줄바꿈 테스트가 필요.
