# RPU 2.4.34 - 전체 MSG 자동 정적 감사 (2026-10-17)

원문 영어/SSL과 수동 대사 검수의 한계를 보완하기 위한 전수 자동 탐지 1회 결과.

| 측정 항목 | 결과 |
|---|---:|
| 한글 대사 MSG | 1,032개 |
| 전체 한글 MSG 고유 ID(헤더 기준) | 57,063개 |
| 기존 말투 검사기가 해석한 내용 항목 | 56,683개 |
| 대조한 고유 SSL 파일 | 1,001개 |
| 말투 혼합 의심 MSG | 251개 |
| 추정 NPC 역할 충돌 | 17건 |
| 단순 종결어미 분류가 가능한 NPC 문장 | 7,001개 |
| 플레이어 Option 제외 | 18,802개 |
| 스크립트에서 직접 화자를 확인하지 못한 항목 | 28,040개 |

명시적으로 구별해야 할 것:

- 말투 혼합 '251개 파일'은 오류 확정이 아님. 한 파일에서 여러 화자가 등장할 수 있고,
  동일 화자의 관계·상황별 의도적 말투 변화가 있음.
- 56,683개는 기존 정규식이 추출한 개수로, 전체 고유 ID 57,063개와 다름.
  개선된 로컬 자동 검수기는 주석을 포함한 57,063개 ID를 식별하지만
  3개 비표준 레코드는 원문 내용을 안전하게 파싱할 수 없어 별도 구조 검수 필요.
- 로컬 모델의 자동 추천은 검증되지 않은 교정 후보이므로 한국어 MSG를 자동 덮어쓰지 않음.
- 재개 가능한 로컬 분석: korean/auto_review_queue.py
- 예약 로컬 실행: korean/run_local_batch.ps1, Windows 작업 스케줄러
  Fallout2-RPU-Overnight-Review
- GitHub Actions의 정적 감사는 작업 브랜치에 번역 변경이 푸시될 때 자동 실행.

자동 검출 결과만으로 게임 내 대사 품질 전수 수동 검수 완료를 선언할 수 없음.
